# Security reporting

Report suspected vulnerabilities privately through
[Fjord Design's private reporting form](https://github.com/Fjord-Design/.github/security/advisories/new).
Reports submitted there are visible to repository administrators and people they
invite to the advisory, rather than being published as public issues.

Include the affected repository, version or commit, reproduction steps, likely
impact and any suggested mitigation. Include only information needed to
reproduce the problem; remove unrelated personal data and credentials.

Do not post exploit details or secrets in public issues, discussions or pull
requests. Maintainers will assess the report and coordinate a fix and disclosure
with the reporter. No response-time or support-lifetime guarantee is currently
published; report the exact version so maintainers can establish the affected scope.

If a repository publishes its own security policy, follow that policy instead.
