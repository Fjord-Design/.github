# Fjord Design community

Organization profile, brand assets and shared contribution defaults for
[Fjord Design](https://github.com/Fjord-Design).

- `profile/README.md` is the public organization profile.
- `assets/` contains the organization emblem and its generation record.
- `CONTRIBUTING.md` and `SECURITY.md` provide shared contributor guidance.
- `.github/` contains issue and pull request templates.

Project-specific guidance takes precedence over these defaults. Design tokens
belong in `fjord-design`; KDE implementation work belongs in `fjord-kde`.

This repository is public. Do not put private source code, credentials, personal
contact information or unpublished security reports here.

The organization emblem is separate from the foundation's existing SVG brand
assets. See [asset provenance](assets/GENERATION.md) for the approved artwork.

## Maintaining this repository

Use a focused branch and conventional commits. Before pushing, run
`git diff --check`, verify local links and image references, and preview the
profile on GitHub. No runtime or build step is required.
